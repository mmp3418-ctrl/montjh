# Begonia Club · Garden City Company LLC

موقع ويب حديث لشركة مدينة الحدائق ذ.م.م (التعاون الاستثماري السياحي) ونادي بيغونيا.

## التشغيل

```bash
npm install
npm run dev
```

## البناء للإنتاج

```bash
npm run build
npm run preview
```

## التقنيات

- React 19 + TypeScript (strict)
- Vite
- Tailwind CSS v4
- Lucide Icons
- تخطيط عربي RTL كامل
